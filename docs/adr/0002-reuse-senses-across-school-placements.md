# Reuse one Sense across school placements and learning sets

The owner accepted reusing an existing suitable Sense across multiple grades
and learning sets while preserving its identity and learning progress, rather
than duplicating vocabulary rows for each class. Placement and child-appropriate
wording/examples belong to curated pedagogical context; a genuinely different
meaning retains a different Sense identity. This prevents fragmented progress
and allows one meaning to serve children and adult beginners without overwriting
the canonical wording for everyone. Existing runtime grade projection supports
only one grade; implementing multi-grade placements or content variants still
requires an additive contract/import/read-model change. No migration or backfill
is performed by this decision. See the local content audit dated 2026-10-28.

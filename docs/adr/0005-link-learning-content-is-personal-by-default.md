# Vocabulary derived from links is personal by default

The owner chose personal learning sets for the user importing a YouTube or English
article link, rather than automatically expanding the shared catalog. Source-
specific selections and interpretations therefore stay private to their owner;
an import does not publish them for everyone. This avoids letting one user's
source selection change the shared curated learning content, while requiring an
explicit ownership boundary. Q27 subsequently accepted reusing the same suitable
shared sense/progress, while new meanings remain personal and source context stays
with the personal set. Preview/selection and manual text/subtitle fallback were
accepted in Q25/Q26. Q28–Q33 subsequently accepted text-first cards, no new media
generation, existing-account-only imports, normal learning/review for private content,
AI drafts reviewed before save, batches of at most 30 selected cards and no new paid
spending. Importing itself does not count as learning. Storage/API/private content
authority, verified providers/allowances and any later sharing flow still need
implementation design. No extraction provider, new row identity, AI/media call or
data import is authorized by this decision alone.

Q34 clarification: the owner replaced the proposed card-import core with learning
directly through original video/voice and bilingual subtitles. The prior card-first
scope and ≤30-card batch are historical, not a confirmed video-learning contract.
The personal-by-default boundary remains; active video decisions are in
`docs/plans/practice-and-link-learning-2026-11-01/video-learning.discovery.md`.

Q43 accepted existing-account login before link processing/saving, a private video
library, bookmarks/positions/results and same-device active-session continuation.
This preserves the ownership boundary without requiring a flashcard-import flow.

Q44 confirmed the complete video-v1 product contract and consolidated plan,
including these boundaries. The analysis is closed; no implementation requested.
